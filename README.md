# the_car

Симулятор автомобиля ВАЗ-2106 с веб-панелью, телеметрией, автопилотом и TCP-консолью.

## Запуск

Нужен Docker Compose. Используйте готовый `.env` без изменений. Из каталога сервиса выполните:

```sh
docker compose up --build -d
```

Веб-панель и API доступны на `http://localhost:8080`. Автопилот слушает порт `8888`, TCP-консоль - `31337`.
